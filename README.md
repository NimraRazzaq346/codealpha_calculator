A responsive and user-friendly calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean interface, smooth interactions, and a modern design.

## 📌 Project Overview

This calculator is designed to provide a simple and interactive calculation experience. It supports essential mathematical operations and includes additional features to improve usability.

## ✨ Features

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Clear All (AC) functionality
- Delete last digit (DEL)
- Real-time calculation display
- Responsive user interface
- Keyboard support
- Modern UI with muted green colors
- Smooth hover effects and button interactions

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the calculator |
| CSS3 | Styling, layout, and animations |
| JavaScript | Calculation logic and functionality |

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Locate the `index.html` file.
4. Open it in your browser.
5. Start performing calculations!
